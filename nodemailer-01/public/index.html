If your email account has Two-Factor Authentication (2FA) or an Authenticator App enabled, your regular login password will NOT work for SMTP. You need to generate a special App Password instead.

📧 Gmail / Google
Google Account → Security → 2-Step Verification → App Passwords → Select "Mail" → Generate 16-char password
📬 Outlook / Hotmail
Microsoft Account → Security → Advanced Security → App Passwords → Create new
📮 Yahoo Mail
Yahoo Account → Security → Generate App Password → Select "Other App" → Generate
📩 Zoho Mail
Zoho Account → Security → App-Specific Passwords → Generate new password
💡 Tip: Use the generated App Password in the "SMTP Password" field below — not your regular login password. App Passwords are typically 16 characters (e.g. abcd efgh ijkl mnop). Each can be revoked individually without affecting your main account.
